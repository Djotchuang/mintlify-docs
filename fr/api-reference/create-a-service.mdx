Pour utiliser nos endpoints API, vous devez [créer un **service**](https://www.fapshi.com/fr/aide-et-support/how-to-create-a-service-to-get-api-credentials). Un service représente la plateforme ou l’application que vous souhaitez utiliser pour **collecter** ou **effectuer des paiements**. Il existe deux types de services :

1. **Service de Collecte** : Utilisé pour collecter de l’argent sur votre plateforme. Tous les fonds seront visibles dans ce service sur votre tableau de bord.
2. **Service de Déboursement** : Utilisé pour effectuer des paiements programmés à partir de votre plateforme.

<Note>
  Vous ne pouvez pas utiliser un même service à la fois pour la collecte et le
  déboursement. Si vous avez besoin des deux fonctionnalités, vous devez créer
  deux services distincts.
</Note>

<Warning>
  Par défaut, les **retraits** sont désactivés en **mode Live**. Vous devez donc
  [contacter le support](https://wa.me/237658610472) avec votre **API User**
  pour demander l’activation. Cette demande ne doit être faite qu’après avoir
  testé la fonctionnalité avec les clés de test.
</Warning>

## Comment Créer un Service

1. Connectez-vous à votre tableau de bord et cliquez sur **Développeurs** à l’extrême bas gauche de l’écran.

2. Cliquez sur le bouton **Nouveau Service**.

3. Remplissez les informations demandées et validez.

<Info>
  - Le nom du service est le nom de votre site web ou application. - Le nom de
  domaine peut être celui que vous avez déjà acheté ou que vous prévoyez
  d’acheter. Vous n’êtes pas obligé de le posséder immédiatement. Notez que vous
  ne pouvez pas utiliser **fapshi.com** comme nom de
  domaine, car il s'agit du domaine Fapshi.
</Info>

4. Une fois le service créé, ouvrez-le. Vos `apiuser` et `apikey` pour ce service seront affichés ; **Sandbox** sous **Sandbox** et **Live** sous **API**. Copiez-les avec soin, en particulier l'`apikey`, car ils sont sensibles.

5. Stockez les identifiants de manière sécurisée (par exemple, dans un fichier d'environnement ou un coffre-fort sécurisé). Ne les codez pas en dur et ne les validez pas dans des dépôts publics. Pensez également à les renouveler si nécessaire.
