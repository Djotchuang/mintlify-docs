<Tip>NOUS VOUS CONSEILLONS DE RÉALISER LE RECHARGEMENT VIA L’[APPLICATION MOBILE FAPSHI](https://fapshi.com/en/mobile-app). Les étapes ci-dessous s’appliquent donc à l’application mobile.</Tip>

Le rechargement de votre compte Fapshi vous permet d'effectuer des paiements, d'alimenter vos services et de gérer vos activités plus efficacement.

Vous pouvez recharger :

1. **Votre portefeuille principal**
2. **Le solde d'un service**

<Tip>
Les rechargements sont généralement traités en quelques heures et, dans la plupart des cas, au plus tard dans un délai d'un jour ouvrable. En cas de retard, veuillez [contacter le support](https://wa.me/237658610472).
</Tip>

## Méthodes de rechargement

Fapshi prend en charge les méthodes de rechargement suivantes :

- **Transfert Mobile Money / Float**
- **Dépôt bancaire**

Lorsque vous effectuez une demande de rechargement, Fapshi affiche les informations de paiement correspondant à la méthode choisie.

## Recharger votre portefeuille principal

Votre **portefeuille principal** peut être utilisé pour effectuer des paiements et transférer des fonds vers vos services.

Pour effectuer un rechargement :

1. Ouvrez l'onglet **Gérer les fonds**.
2. Sélectionnez **Rechargements**.
3. Appuyez sur **Demander un rechargement**.
4. Saisissez le montant à recharger.
5. Consultez les informations de paiement affichées.
6. Effectuez le transfert via Mobile Money, Float ou dépôt bancaire.
7. Téléversez votre preuve de paiement.
8. Soumettez votre demande.

<Info>
Vous recevrez un e-mail une fois votre rechargement vérifié et votre portefeuille crédité.
</Info>

## Recharger un service

Il existe deux façons de recharger un service.

### Option 1 : Déposer des fonds directement dans le service

Cette méthode vous permet d'effectuer un dépôt directement sur un service.

Pour cela :

1. Ouvrez l'onglet **Services**.
2. Sélectionnez le service que vous souhaitez recharger.
3. Appuyez sur **Recharger ce service**.
4. Saisissez le montant à recharger.
5. Consultez les informations de paiement affichées.
6. Effectuez le transfert via Mobile Money, Float ou dépôt bancaire.
7. Téléversez votre preuve de paiement.
8. Soumettez votre demande.

<Info>
Vous recevrez un e-mail une fois votre rechargement traité.
</Info>

### Option 2 : Transférer des fonds depuis votre portefeuille principal

Si votre portefeuille principal dispose déjà de fonds, vous pouvez les transférer instantanément vers l'un de vos services.

Pour cela :

1. Ouvrez l'onglet **Services**.
2. Sélectionnez le service que vous souhaitez recharger.
3. Appuyez sur **Recharger ce service**.
4. Sélectionnez **Recharger depuis le portefeuille principal**.
5. Saisissez le montant.
6. Confirmez le transfert à l'aide de votre code PIN Fapshi.

<Tip>
Les transferts depuis votre portefeuille principal vers un service sont effectués instantanément.
</Tip>

## Délai de traitement

La plupart des demandes de rechargement sont traitées en quelques heures et, dans des conditions normales, dans un délai maximum d'un jour ouvrable.

<Warning>
Si votre rechargement n'a toujours pas été traité après un jour ouvrable, veuillez [contacter le support](https://wa.me/237658610472) en joignant votre preuve de paiement afin d'accélérer le traitement.
</Warning>

## Remarques

- Vous pouvez recharger aussi bien votre **portefeuille principal** que le **solde de chacun de vos services**.
- Les informations de paiement sont générées lors de votre demande de rechargement.
- Veillez à téléverser une preuve de paiement claire afin de faciliter la vérification.
- Tous les soldes sont affichés en **XAF (FCFA)**.
